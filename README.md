# Parking Management System

A Java-based Parking Management System developed using Java Swing, JDBC, and SQLite.

## Features
- Vehicle registration and management
- Parking slot availability tracking
- Parking session management
- Parking reservations
- SQLite database integration
- User-friendly graphical interface

## Technologies Used
- Java
- Java Swing
- JDBC
- SQLite

## How to Run
1. Install Java JDK.
2. Open the project folder in VS Code.
3. Compile the Java source files using the SQLite JDBC driver.
4. Run the main class `com.parkingmanagement.Main`.

## Database
The application uses SQLite to store vehicle details, parking slots, parking sessions, and reservations.
